# Печать и PDF (N6)

Кнопка **Печать / PDF** вызывает обычный `window.print()`. PNG-экспорта и серверного PDF нет.

## Готовность

Печать разрешена только после успешного чтения назначения шаблона и дизайна (в том числе
подтверждённого отсутствия записи), получения и декодирования разрешённых изображений, загрузки
нужных шрифтов, измерения документа и проверки его DOM в фиксированной области A4.
`data-print-ready` — результат этих проверок, а не наблюдение за исчезновением loading-текста.
Мобильный reflow не заменяет проверку A4: проверяется временная копия того же DOM документа
при ширине 794 px, без повторной модели содержания. Копия сразу удаляется.

Ошибка оформления не разрешает напечатать временный стандартный макет. Есть явный повтор чтения.
Недоступный файл предлагает повтор загрузки изображений; автоматического пропуска нет.
Ошибка загрузки шрифта предлагает перезагрузить страницу. Переполнение или потерянная привязка
стикера блокируют печать с объяснением. Ctrl+P до готовности выводит сообщение вместо неполного
рецепта; вне режима «Просмотр» предлагает сначала открыть рецепт.

## Что печатается

Печатается тот же документ, который открыт в просмотре: текущее содержание и сохранённое серверное
оформление. Если содержание отличается от подтверждённой версии, рядом с кнопкой явно указано,
что печатается локальный preview. Несохранённый черновик оформления из «Дизайна» не подмешивается.
Служебные панели, конфликты, PWA, формы и меню не занимают места в печатной раскладке.

Print CSS задаёт фиксированную A4-область, нулевые внешние поля браузерной страницы и внутренние
поля документа. Размеры шрифта заголовков и заметок не зависят от viewport. Светлый бумажный профиль
переопределяет цвета только в print media; сохранённая тёмная тема и её шрифты не изменяются.
Источник имеет безопасный HTTP(S) href и печатную атрибуцию с доменом; полный адрес сохраняется
в аннотации ссылки PDF. Непроверенная ссылка локального черновика не становится активной.
Длительность шага передаётся без округления: 30 сек, 1 мин, 1 мин 30 сек.

## Автоматизация

Перед browser-тестами установите `python3 -m pip install -r scripts/requirements-pdf-tests.txt`.
На Windows укажите абсолютный путь к Python с pypdf через `TASTORY_PDF_PYTHON`, если команда
`python` отсутствует в PATH. Зависимость устанавливается в локальное виртуальное окружение, не меняя
системный Python. Обычный CI и Publish staging PDF-проверку не запускают.

| Проверка                                                                                                     | Chromium desktop/mobile | WebKit                | Firefox                 |
| ------------------------------------------------------------------------------------------------------------ | ----------------------- | --------------------- | ----------------------- |
| Готовность, медленное фото, недоступное оформление, локальный preview                                        | Да                      | Да                    | Ручной локальный прогон |
| Print CSS, A4 DOM, светлый профиль, скрытие панелей                                                          | Да                      | Да                    | Ручной локальный прогон |
| Реальный PDF, размер листа, все фрагменты ровно один раз, источник, изображения, непустая последняя страница | Да                      | Нет API генерации PDF | Нет API генерации PDF   |

Новые сценарии имеют префикс `N6 print`. PDF инспектируется отдельным read-only скриптом через
pypdf, а не поиском строк внутри бинарного файла. Локальные отчёты и ошибки сохраняются обычным
auth-report. В fixtures фотографии — настоящие синтетические JPEG, не PNG с неверным MIME. Базовый
Playwright runner напрямую владеет Vite preview и закрывает его в teardown; это устраняет зависший
дочерний npm-процесс на Windows.

Windows Firefox исключён из локального запуска из-за уже зафиксированной проблемы создания
страницы в Playwright/Node; его ручная проверка требует подходящего Linux-окружения. WebKit —
проверка движка, не системного диалога Safari.

## Отдельная live-приёмка

Не подтверждены автоматически: системные диалоги печати, физический принтер, мобильное меню
печати ОС, реальные Drive-файлы и доступ пользователей. В диалоге выберите A4, масштаб 100%,
отключите браузерные колонтитулы; фоновые изображения включите для полного декоративного вида.
Доступные шрифты ОС могут различаться, поэтому пагинация измеряется на текущем устройстве.
Live deployment и вход владельцем (который может инициировать миграцию) требуют отдельного
согласования. Этот этап не запускает миграций книги.
