# Библиотека рецептов

Рабочая копия содержит R-06: сетку и список, поиск по названию и ингредиентам, фильтры по состоянию, видимости, тегу и избранному, четыре порядка сортировки и личное избранное.

Состояние выдачи хранится в URL. Ссылку с запросом и фильтрами можно открыть повторно, а неизвестные значения безопасно заменяются настройками по умолчанию. Поиск выполняется по облегчённым сводкам: сервер возвращает название, описание, время, имена ингредиентов, теги и ID обложки. Заметки, шаги и файлы фотографий в список не входят. Миниатюра обложки запрашивается отдельно, только при приближении карточки к viewport и только после повторной проверки права на рецепт. Ушедшая из области загрузки карточка освобождает ресурс; общий pool разделён по аккаунту и очищается при выходе.

Пустая библиотека показывает локальный демонстрационный рецепт через тот же renderer и четыре шага основного пути. Demo явно помечено, не загружает приватные файлы и не создаёт серверный рецепт. Его можно закрыть отдельно для сочетания API и аккаунта. Создание черновика и подготовка серверного хранилища выполняются только явными кнопками пользователя.

Личное избранное хранится в таблице `RecipeFavorites`, добавленной миграцией `005-recipe-library` (схема 5). Изменение записывается как добавочная операция с уникальным request ID. Повтор того же запроса возвращает прежний результат, а повтор ID с другим содержимым отклоняется. Пользователь может добавить в избранное любой доступный ему рецепт; отметки других пользователей в API не выдаются.

Перед использованием в Google нужно опубликовать согласованные frontend и Apps Script, затем владельцу отдельно подтвердить подготовку хранилища. Переход со схемы 4 создаёт только `RecipeFavorites`; миграция повторяема и не меняет версии рецептов.
