# ADR 0010: Четыре референсных семейства книжных страниц

Дата: 2026-09-05  
Статус: предложено до визуального согласования

## Контекст

Десять существующих layout уже могут быть сохранены в рецептах и переносимых файлах, поэтому их ID и
геометрия не должны меняться. Для следующего визуального этапа предоставлены четыре референса: чистая
монохромная карточка, мягкий цветной дневник, спокойная иллюстрированная тетрадь и розовый блокнот с
пружиной. Референсы задают композицию и ритм, но не разрешают копировать иллюстрации, выдуманные поля
пользы, сложности или пищевой ценности.

## Решение

Добавляются четыре новых layout ID и встроенных шаблона категории `dish`:

| Layout ID         | Название           | Композиционный признак                                                           |
| ----------------- | ------------------ | -------------------------------------------------------------------------------- |
| `pastel-notebook` | Пастельный блокнот | Почти равные самостоятельные блоки, декоративная пружина, фото-полароид          |
| `berry-diary`     | Ягодный дневник    | Заголовок и органическое фото рядом, две мягкие карточки, ленты и округлая рамка |
| `lined-notebook`  | Линованная тетрадь | Кремовые линии, фото рядом с вводной частью, спокойная асимметрия колонок        |
| `clean-card`      | Чистая карточка    | Строгий заголовочный блок, тонкие разделители, две типографические колонки       |

Все варианты строятся тем же `RecipePageDocument`: сохраняемый дизайн содержит только layout/theme и
авторские элементы, а координаты текста и результаты пагинации вычисляются renderer. Обложка, теги,
источник, фото и стикеры проходят тем же ресурсным слоем, что у прежних layout. Декор выполняется CSS и
семантическими цветами текущей темы страницы; сетевые шрифты и изображения из референсов не добавляются.

## Альтернативы

- Переоформить четыре старых layout — отклонено: изменился бы вид уже сохранённых рецептов.
- Сохранить референсы как фон страницы — отклонено из-за лицензирования, недоступности текста и
  невозможности корректной пагинации.
- Создать отдельные HTML-макеты — отклонено: просмотр, дизайн и PDF снова разошлись бы.

## Последствия

Каталог содержит четырнадцать встроенных вариантов: десять прежних и четыре additive-семейства. Старые
ID, fallback `hearth` и версия документа остаются неизменными. Новые ID требуют backend с обновлённым
контрактом до публикации соответствующего frontend.

## Проверка и пересмотр

До принятия ADR нужны screenshots одного короткого и одного длинного рецепта для desktop 1440 px,
mobile 390 px и A4, а также проверка 320 px. После одобрения изображения становятся visual-regression
эталонами. До этого они являются review-артефактами, а не утверждёнными golden-файлами.
