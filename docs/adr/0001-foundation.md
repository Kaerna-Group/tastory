# ADR 0001: Лёгкий монорепозиторий и FSD

Дата: 2026-09-02  
Статус: принято

## Контекст

Web и Apps Script используют одинаковые контракты. Данные рецепта должны жить независимо от оформления и Google-хранилища.

## Решение

npm workspaces: apps/web, apps/apps-script, packages/contracts, domain, design-tokens. Пакеты экспортируют TypeScript через явный public API; сборкой занимается потребитель. FSD применяется только внутри web. Направление импортов и циклы проверяются собственным небольшим правилом на TypeScript AST с тестами.

## Альтернативы

Nx/Turborepo и отдельная сборка каждого пакета добавляют конфигурацию без текущей необходимости. Steiger остаётся возможной заменой собственного правила при усложнении FSD.

## Последствия

Одна установка, один lockfile; отдельный typecheck каждого workspace. Пакеты не предназначены для прямого запуска Node или публикации. Новые архитектурные исключения требуют изменения проверки и теста.

## Пересмотр

Появление большого числа приложений, publishable packages или необходимость build cache.
