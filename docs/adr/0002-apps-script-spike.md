# ADR 0002: Apps Script принимается после проверки платформы

Дата: 2026-09-02  
Статус: условно принято; удалённый gate открыт

## Контекст

Blueprint предлагает Google Sheets/Drive для 5–10 пользователей. Риски — Google JWT, CORS с redirect, приватные файлы, конкуренция и квоты.

## Решение

Подготовить сборку Apps Script, общий API v1, health/echo и сменный transport. Разработку core data layer начинать после доказательства критических сценариев этапа 0. SchemaVersion=0 и not-configured честно обозначают отсутствие данных/auth.

Echo выключен по умолчанию. Текущие endpoints не принимают credentials и не имеют доступа к пользовательским данным.

## Альтернативы

Node/edge backend с базой данных остаётся вариантом, если gate не пройден. No-cors и публичные Drive-файлы не решают требования приватного приложения.

## Последствия

Можно работать над основой без Google. Удалённая работоспособность не выводится из локальных тестов. Для Google-проверок нужен аккаунт владельца, отдельные ресурсы и опубликованный origin.
