# Конструктор тем V-04

Конструктор находится в настройках и оформляет две независимые области: весь интерфейс Tastory и открытые страницы рецептов. Выбор хранится в текущем браузере и применяется до загрузки React, поэтому при открытии страницы нет вспышки другой темы.

## Возможности

- четыре встроенные темы, каждая копируется перед изменением;
- восемь разрешённых цветов палитры без произвольного CSS и URL;
- светлый и тёмный режим нативных элементов;
- три системные пары шрифтов без сетевой загрузки;
- чистая, льняная, точечная и клетчатая бумага;
- живой предпросмотр заголовка, текста, карточки и основной кнопки;
- расчёт контраста WCAG для основного, дополнительного текста и кнопки.

Применение блокируется, если хотя бы одно из трёх сочетаний ниже **4.5:1**. Повреждённая или созданная другой версией запись localStorage игнорируется; приложение возвращается к встроенной теме с учётом системного светлого или тёмного режима.

## Границы

Тема страницы меняет визуальные токены редактора и просмотра, но не содержимое рецепта и не его историю. Настройки темы пока локальны для браузера и не добавляют столбцы в схему 6. Синхронизация между устройствами может быть добавлена отдельной миграцией после живого применения схемы пользовательских настроек.
