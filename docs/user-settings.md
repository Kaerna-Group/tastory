# Настройки профиля и редактора

Модуль P1 хранит личные параметры участника в книге и применяет их на каждом устройстве после Google-входа. Настройки принадлежат паре «книга + пользователь»; клиент не может выбрать чужой user ID или workspace ID.

## Что настраивается

- имя внутри Tastory;
- метрические или американские подсказки единиц;
- °C или °F для будущих температурных полей;
- личная или общая видимость нового рецепта;
- просторный или компактный редактор;
- задержка автосохранения 0,5 / 0,9 / 2 секунды;
- горячие клавиши;
- подтверждение перед удалением фотографий.

Тема браузера остаётся локальной настройкой внешнего вида. Профиль и параметры редактора синхронизируются сервером.

## Надёжность

Миграция `006-user-settings` добавляет лист `UserSettings`. Каждое изменение — полный неизменяемый снимок с `base_revision`, новой ревизией и устойчивым `request_id`. Повтор того же запроса возвращает прежний результат; тот же ID с другим содержимым отклоняется. Устаревшая ревизия даёт понятный конфликт. Лист входит в резервную копию и восстановление книги.

Клиент сохраняет незавершённый ID записи в `localStorage`, поэтому после неопределённого ответа отправляет тот же запрос и не создаёт повтор. До первого серверного снимка используются безопасные значения: личный рецепт, метрические единицы, 0,9 секунды и подтверждение удаления.

## Клавиатура и мобильный экран

При включённых сочетаниях `Ctrl/⌘ + S` сохраняет сейчас, `Alt + Shift + I` добавляет ингредиент, `Alt + Shift + S` добавляет шаг, `?` открывает справку, `Esc` закрывает её. Сочетания добавления не срабатывают в режиме чтения.

Форма настроек и редактор переходят в одну колонку на узком экране. Основные поля и действия имеют высоту не меньше 44 px; справка открывается как нижняя панель и не создаёт горизонтальную прокрутку.

## API

- `user.settings.get`, payload `{}` → `kind: "userSettings"`, `outcome: "read"`;
- `user.settings.update`, payload `{ expectedRevision, value }` → `outcome: "committed" | "replayed"`.

Ошибки: `SETTINGS_NOT_READY`, `SETTINGS_CONFLICT`, `SETTINGS_UNAVAILABLE`, а также общий `OPERATION_MISMATCH`. Оба действия требуют действующий Google credential и активное членство.
